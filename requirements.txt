# What the weekly workflow installs.
#
# One package. Everything else the pipeline needs at run time comes from the
# Python standard library.
#
# The short list is deliberate. Every package installed here runs its own code
# inside the job that holds TMDB_API_KEY, so a package that does nothing in
# Actions is not free: it is more third-party code beside a secret, and one more
# maintainer account whose compromise would reach this pipeline. The test runner
# and python-dotenv used to be installed here and did nothing in CI. They are in
# requirements-dev.txt now.
#
# Each entry is pinned to its current major version, so a new major release can
# never arrive on its own and break a run nobody is watching.

# HTTP client for the RSS feed, the curated list pages, and the TMDB API.
# httpx is still below 1.0, so its minor version is the compatibility boundary.
httpx>=0.28.1,<0.29
